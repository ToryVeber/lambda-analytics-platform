# Data Schemas: Web Traffic & A/B Testing

## 1. Bronze Layer (Raw Ingestion)
This table acts as a high-throughput landing zone for the raw event stream incoming from the Snowplow collector into Apache Kafka.

### Table: `bronze.snowplow_web_events_raw`
* **Storage Engine:** Apache Kafka Topic (`snowplow_web_events`) 
* **S3 Storage Location:** `s3://ecom-platform-bronze/snowplow_web/year=YYYY/month=MM/day=DD/`
* **Schema:**

  | Column Name | Data Type | Nullable | Description |
  | :--- | :--- | :--- | :--- |
  | `batch_id` | String | NOT NULL | Unique message identifier generated by Kafka or the collector for the entire payload request. |
  | `raw_payload` | String (JSON) | NOT NULL | The complete, unparsed JSON batch payload conforming to Snowplow payload_data jsonschema (contains the `data` array of events). |
  | `ingested_at` | Timestamp | NOT NULL | The execution timestamp when the data platform successfully caught and stored the message. |

## 2. Silver Layer (Cleaned & Sessionized)
Apache Spark parses the raw Snowplow JSON, filters out corrupt records, flattens performance metrics, parses user-agent/geography data, and adds computed session identifiers.

### Table: `silver.user_events`
* **Storage Engine:** Apache Iceberg over Garage S3
* **Schema:**

  | Column Name | Data Type | Nullable | Description |
  | :--- | :--- | :--- | :--- |
  | `event_id` | String | NOT NULL | Deduplicated unique event UUID. |
  | `device_id` | String | NOT NULL | Client-side cookie ID (`domain_userid` from Snowplow). |
  | `user_id` | String | NULLABLE | Authenticated user ID from the internal CRM/OLTP system. |
  | `session_id` | String | NOT NULL | Session hash calculated by Spark (30-minute inactivity window). |
  | `event_name` | String | NOT NULL | Action type (`page_view`, `add_to_cart`, `purchase`). |
  | `utm_source` | String | NULLABLE | Marketing source parsed by Snowplow (`mkt_source`). |
  | `utm_medium` | String | NULLABLE | Marketing medium (`mkt_medium`). |
  | `device_type` | String | NOT NULL | Parsed category of device (`desktop`, `mobile`, `tablet`). |
  | `os_name` | String | NOT NULL | Operating system name (`iOS`, `Android`, `Windows`, `macOS`). |
  | `country` | String | NULLABLE | ISO country code determined via GeoIP (e.g., `PL`, `DE`). |
  | `page_load_time_ms` | Integer | NULLABLE | Web performance: full page load duration in milliseconds. |
  | `http_status` | Integer | NOT NULL | HTTP response code (e.g., 200, 500) to monitor errors. |
  | `ab_test_id` | String | NULLABLE | Active experiment identifier. |
  | `ab_variant` | String | NULLABLE | Assigned experiment group (`A` or `B`). |
  | `event_timestamp` | Timestamp | NOT NULL | Client-side exact timestamp of the interaction. |

## 3. Gold Layer (Analytical Data Marts)
dbt orchestrates heavy aggregations inside ClickHouse, shifting detailed user logs into high-performance columnar tables optimized for sub-second BI dashboards.

### Table: `gold.ab_test_performance`
* **Storage Engine:** ClickHouse (`SummingMergeTree` or `ReplacingMergeTree`)
* **Primary Key / Order By:** `(test_id, variant_id, traffic_source, device_type, country)`
* **Schema:**

  | Column Name | Data Type | Description |
  | :--- | :--- | :--- |
  | `test_id` | LowCardinality(String) | Unique identifier of the A/B experiment. |
  | `variant_id` | LowCardinality(String) | Experiment group assignment (`variant_A` or `variant_B`). |
  | `traffic_source` | LowCardinality(String) | Unified traffic channel (`google`, `yandex`, `organic`, `email`). |
  | `device_type` | LowCardinality(String) | Detected device category (`desktop`, `mobile`, `tablet`). |
  | `country` | LowCardinality(String) | Customer country code determined via GeoIP (e.g., `PL`, `DE`). |
  | `total_users` | UInt64 | Total distinct users (`device_id`) exposed to this exact segment. |
  | `conversion_rate` | Float64 | Product metric: `unique_buyers / total_users` ratio. |
  | `cart_abandonment_rate` | Float64 | Product metric: percentage of sessions with `add_to_cart` but no `purchase`. |
  | `p50_page_load_time` | Float64 | Technical metric: Median page load duration in milliseconds. |
  | `p95_page_load_time` | Float64 | Technical metric: 95th percentile page load duration. Identifies slow loads. |
  | `error_rate` | Float64 | Technical Health: Percentage of internal server errors (`http_status >= 500`). |
  | `updated_at` | DateTime | Execution timestamp of the last dbt build. |
